Start a run

Runs take about 5 to 20 minutes. You can leave this page; the draft shows up under Kits.
  • Safe by design. A run only ever saves a new draft. Approving is your click, from a staff login; an API key can start a refresh but can't approve or unlock rules.
  • Checked twice. Every draft runs the kit check (banned words, HTML Milanote can't paste, missing links, no Sources card) and the studio judge before it reaches you. A draft that failed the judge is still saved, marked, so you can see what went wrong.
  • What still needs a person. New template images (the agent describes them; a designer makes them), and anything behind an Instagram login, which the agent marks as not re-checked.
