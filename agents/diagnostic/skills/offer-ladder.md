# The Offer Ladder

Where the diagnostic leads. The $999 assessment is the top of the funnel; the implementation tiers are where the revenue is. Recommend the tier that fits what the client said — not the most expensive one.

## The ladder

| Tier | What it is | Price |
|---|---|---|
| **Diagnostic** | The AI-tools assessment itself — 45-min interview → report → review call. | **$999** (waived if they sign implementation within 7 days) |
| **Automation Build** | Zapier / Make / n8n flows. Build, train, hand off. Best for 1-3 step repetitive tasks. | **$1-3K** |
| **Process Redesign** | Map current → future, eliminate the waste. For a broken process, not just a missing tool. | **$3-5K** |
| **Custom Workflows** | Prompts + templates + one-click operations for a specific workflow. | **$3-5K** |
| **Knowledge Systems** | A custom GPT / Claude project trained on their content library. For repeated-question / repeated-answer pain. | **$3K+** |
| **Concierge Retainer** | Two 45-min calls/month · Voxer access between calls · 12 business-hour response. The ongoing AI operator. | **$1,200/mo** |

Value framing on the retainer: two calls + async access = **$500+/hour of your time**. What you cover in-session: set up Claude cowork, build Claude projects per business function, build skills for their existing workflows, ongoing AI concierge.

## Tier selection logic (drives the Offer Strategist)

Route on the client's three closing answers — most urgent, DIY-or-help, timeline:
- Urgent pain is a **1-3 step repetitive task**, wants help, near timeline → **Automation Build**.
- Pain is a **broken/wasteful process** end-to-end → **Process Redesign**.
- Pain is **answering the same thing over and over** (email, FAQs, buyer questions) → **Knowledge System**.
- Pain is a **specific recurring workflow** they run manually → **Custom Workflow**.
- Need is **continuous / evolving** → **Concierge Retainer** (also the DIY-teach-me path).

Always offer the **$999 waiver** as the close mechanic: "$999 for the assessment, or waived if you move forward within 7 days." Be creative with bundles when it serves the client (e.g. Automation Build + one month concierge so it sticks). Give credit toward packages to upsell.

## What makes it feel premium
- Google Forms onboarding before Call 1 (skip the interview cold-start).
- Named Drive folder with full call recordings.
- One-pager per call: top 3 action items before the next session.

## Case-study proof (lead with the real result)
- **Knowledge System (business-listing GPT):** seller answered 0 of ~450 repetitive buyer emails; buyers called it the best business-buying experience they'd had. Two levers — efficiency + quality.
- **Automation Build (wedding-planning ops):** operations manager was duplicating a workspace by hand every event; moved the repetitive build to an automation. A 30-min manual task, left alone, becomes a 2-hr/week drain as the business grows — automating early captures the compounding.

## The Hooks anchor (TOJ's own proof)
TOJ built its own operating brain first — the `hooks-os` skills library, the Supabase/GHL automation infrastructure, and the agent stack running at tojcampaign.com/admin. That is the T2 "Operating Brain" proof: when a prospect asks "does this actually work," the answer is a versioned repo and a live agent console, not a promise. Use it.

## Per-vertical framing

The diagnostic motion is vertical-agnostic; the pain language changes. See `docs/TOJ-Diagnostic-Offer.md` for the full playbook.
- **Football-trainer** (fbtrainer / hooks-os / STL): recap cadence, referral-tag discipline, roster health, session capacity. Diagnostic $999 · retainer ~$2,500/mo (high athlete-referral LTV).
- **Small-business** (smallbusiness): money-in-the-door visibility, invoice chase, month-end close, customer pulse. Diagnostic $999 · retainer ~$1,200/mo.
- **Authority-creator** (Subject Media / Subject Report): content cadence, brand-voice drift, case-study production, personal-LLM appetite. Diagnostic ~$2,500 · retainer ~$3,000/mo.
