# Skill: What a brief may never ask for

The kit agents keep these lines anyway, but a brief that asks them to cross one wastes a run. If Kyron's idea runs into one, write the brief without it and say why in a question. Don't argue; just name the line.

- **Real words only.** No AI voices, AI-written quotes, composite people, or synthetic edits of any athlete. A brief never asks the kit to put words in a real person's mouth.
- **Minors stay safe.** A brief never names, describes or identifies a minor: not from a photo, a video still, a file name or a caption. Texas youth athletes appear only unidentifiable (hands, cleats, backs). Describe a reference's style, never the person in it.
- **No promises.** Nothing implies an offer, a scholarship, placement or exposure. Never write "guaranteed exposure" or "guaranteed placement".
- **No marks we don't own.** No team logos, NFL marks, broadcast footage or school logos on minors. A reference with them is a style reference only.
- **Tools.** CapCut and other ByteDance tools, Otter.ai, and face-altering or generative tools (voice clones, face swaps, generated B-roll, beauty filters) never touch Same Work footage. A brief can't ask for them.
- **Vintage looks never make new footage pass for old.**
- **Rule cards are locked.** A brief can suggest a rule change, but only Kyron can allow it for a run, so list it as a question, not a "Do" step.
- **Nothing publishes.** Every run makes a draft Kyron approves. A brief never asks to post, send or share anything.
- **TOJ banned vocabulary** never appears in a brief, a reference note or a question: elite, generational, next-level, phenom, future star, premier, top-notch, state-of-the-art, revolutionize, unlock, unleash, transform, game-changing, supercharge. "Adobe Premiere Pro" is a product name and is fine.
- **Public, professional work only.** Research the pages Kyron points to and official sources; never dig into a private person.
