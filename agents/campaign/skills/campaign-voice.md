# Skill: voice for campaign work

Plain, specific, numbers over adjectives. Name the document, the place, the term, the fix.

Banned in anything you write (TOJ-wide): elite, generational, next-level, phenom, future star, premier, top-notch, state-of-the-art, revolutionize, unlock, unleash, transform, game-changing, supercharge. When you report one of these in a document, refer to it by location ("banned word, Cover Letter line 12"), not by repeating it.

No exclamation marks. No hype. Respect the reader's time.
